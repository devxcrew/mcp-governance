# UIUX Assist Documentation

This folder explains the UIUX repository, its external dependencies, its work boundary, and its verification process.

## Read order

1. Read [repository map](repository-map.md) to understand ownership and external repositories.
2. Read [development guide](development.md) before changing source files.
3. Read [verification guide](verification.md) before reporting a result.

## Application summary

UIUX is a standalone browser gallery for the public CODEXSUN UI package. It shows layouts, pages,
blocks, templates, components, variants, and code examples in a live browser.

UIUX does not own business modules, an API, identity, storage, or a database. It does not import
source code from application repositories.
