# UIUX Development

Run commands from D:\codexsun\devkits\uiux. Gallery code belongs here; reusable components belong to D:\codexsun\shared\ui and are consumed through public @codexsun/ui exports.

npm install installs the web workspace and shared UI dependencies. npm run dev starts the gallery on port 6102. Configure web/.app.env using web/.app.env.example. Keep local environment files out of Git.

Run npm run verify for directory, type, and production build checks. Inspect the overview and representative component, block, layout, page, and template previews in the browser. Cxsun runs separately on port 5173.
